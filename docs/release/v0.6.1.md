# v0.6.1 — 업데이트 오류 복구 안정화

업데이트 설치 처리 중 저장소나 잠금 해제 오류가 발생해도 다시 확인할 수 있도록 보완했습니다.

- **오류 복구**: 업데이트 시도 기록에 접근할 수 없거나 잠금 해제가 실패해도 설치 실패 상태를 표시하고 재시도를 막지 않습니다.
- **검증**: Windows 분리 WebView의 두 창에서 업데이트 준비 신호에 따른 미저장 작업 감지·입력 잠금·해제와 편집 내용 유지를 확인했습니다. 해당 시험은 실제 업데이트 설치를 수행하지 않았습니다.

Linux 실제 GUI와 Windows 설치본 파일 연결·실제 업데이트는 확인하지 못했습니다.
