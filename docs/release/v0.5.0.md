# v0.5.0 — PDF 읽기 지원

PDF 파일을 앱에서 페이지 단위로 읽고 탐색할 수 있습니다.

- **PDF 보기**: 페이지 이동과 확대·축소, 텍스트 검색, 문서 목차 이동을 지원합니다. 현재 페이지만 표시하며 PDF 구성 요소는 파일을 열 때 지연 로드합니다.
- **안전한 읽기**: PDF는 읽기 전용이며 100 MiB까지 엽니다. 암호화 또는 손상된 문서는 오류를 표시합니다.
- **검증**: Windows 테스트 WebView에서 페이지·목차·검색과 암호화·손상 파일 오류를 확인했습니다.

검색은 일치하는 페이지로 이동하며 페이지 내 강조 표시는 제공하지 않습니다. 암호화 PDF와 PDF 편집은 지원하지 않습니다. Linux GUI와 설치본의 실제 파일 연결·자동 업데이트는 직접 검증하지 않았습니다.
