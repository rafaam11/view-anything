# v0.15.0 — 최근 파일과 코드 강조

자주 쓰는 흐름을 줄였습니다. 최근에 연 파일을 빈 창과 파일 메뉴에서 바로 다시 열고, 텍스트 뷰어에서 코드를 구문 색으로 읽고 편집하며, 명령줄에서 텍스트로 열거나 3D 화면을 PNG로 저장할 수 있습니다.

- **최근 파일**: 연 파일을 최근 순으로 20개까지 기억합니다. 빈 창 안내 아래와 모든 뷰어의 **파일 > 최근 파일**에서 다시 열며, 드롭·`Ctrl+O`와 같은 규칙으로 창을 고릅니다. 목록은 열린 모든 창이 함께 쓰고 같은 메뉴에서 지울 수 있습니다. 없어진 파일을 누르면 알리고 목록에서 뺍니다.
- **구문 강조**: C/C++ · Python · Rust · JS/TS · 셸 · PowerShell · 배치 · SQL · Java · C# · Go · Ruby · Lua · XML/HTML · CSS/SCSS · INI/TOML 파일을 색으로 표시합니다. 편집 · 선택 · 검색은 그대로이며, 입력하는 동안 잠시 기본 색으로 보였다가 멈추면 다시 칠합니다. 강조 엔진과 언어는 코드 파일을 열 때만 불러와 시작 속도에 영향이 없습니다. 100만 자 · 2만 줄을 넘는 파일, 20만 자를 넘는 편집 중 내용은 기본 색으로 두며 설정의 **구문 강조**로 끌 수 있습니다.
- **명령줄 텍스트 열기**: `view-anything --text <파일>`로 확장자와 무관하게 텍스트 뷰어로 엽니다. Linux 파일 관리자가 넘기는 `file://` URI와 상대 경로도 올바른 파일로 엽니다.
- **3D 화면 PNG**: **파일 > 화면을 PNG로 저장**으로 지금 보이는 장면을 저장합니다. 내보낸 HTML에서도 보기 메뉴에서 같은 이미지를 내려받습니다.
- **정확성 검사**: Biome lint(정확성 규칙)를 CI에 추가하고 지적된 24곳을 고쳤습니다. PDF 배율(25~300%)과 페이지 번호 범위에 회귀 테스트를 더했습니다.
- **로컬 검증**: JavaScript 737개 통과 · 2개 건너뜀, Rust 65개 통과와 타입 검사 · lint · 빌드 · 번들 검사 · clippy(1.99.0)를 확인했습니다. 진입 청크는 39KiB입니다.
- **한계**: 강조 오버레이의 글자 정렬은 Windows(Chromium) 기준으로 측정했고 Linux WebKitGTK와 한글 IME 조합 중 표시는 미검증입니다. 연결이 끊긴 네트워크 드라이브의 최근 항목을 누르면 응답을 기다리는 동안 창이 멈출 수 있습니다. 텍스트로 연 파일은 최근 목록에서 다시 열 때 확장자에 맞는 뷰어로 열립니다. 축 라벨은 PNG에 들어가지 않습니다.
