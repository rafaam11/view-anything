# v0.13.1 — 큰 Markdown, 로그, CSV를 더 안정적으로

사용 중 바로 체감되는 결함을 모아 고쳤습니다. Markdown은 다른 뷰어와 같은 읽기 경로를 쓰고, ANSI 색 코드가 든 로그와 Excel이 저장한 CP949 CSV, 따옴표가 섞인 CSV를 열 수 있으며, 저장할 때 파일 권한을 유지합니다.

- **Markdown 읽기 경로**: 다른 뷰어와 같은 원시 바이트 채널로 읽고 10 MiB 상한을 둡니다. 창을 다시 활성화할 때는 크기·수정 시각을 먼저 비교해 바뀐 경우에만 파일을 읽습니다.
- **ANSI 로그**: 색 코드(ESC)·폼 피드·수직 탭·DOS 파일 끝 표시가 든 로그를 텍스트로 엽니다. UTF-8로 읽을 수 없는 파일과 바이너리(NUL 등 다른 제어 문자)를 구분해 안내합니다.
- **CSV 문자 인코딩**: 설정(`Ctrl+,`)의 문자 인코딩에서 CP949를 선택해 Excel이 저장한 CSV를 열고, 수정한 셀만 같은 인코딩으로 저장합니다. JSON/YAML은 읽을 수 없을 때 원문 오류 대신 "텍스트로 열기" 안내를 표시합니다.
- **CSV 관대 파싱**: 비인용 필드의 큰따옴표와 닫는 따옴표 뒤 문자를 그대로 읽습니다. 셀 한도를 1,000,000개로 올리고(9.5 MB·100만 셀 파싱 약 0.1~0.2초), 열 수 없을 때 "텍스트로 열기"를 제공합니다.
- **읽을 수 없게 된 파일 보호**: 편집 중 다시 읽은 CSV·JSON/YAML이 더는 해석되지 않으면 이전 셀을 남겨 두지 않고 읽기 모드로 돌아가 저장을 막습니다. 예전에는 옛 셀 위치로 저장해 파일이 손상될 수 있었습니다.
- **저장 권한 보존**: 저장할 때 원본의 권한(Linux 실행 비트)을 유지하려 시도하고, 권한 변경을 거부하는 네트워크·FUSE 마운트에서도 저장은 계속됩니다. 읽기 전용 파일(Linux의 쓰기 비트 없는 파일 포함)은 속성을 바꾸지 않고 안내합니다.
- **링크·단축키·확인창**: 읽기 모드 링크 우클릭이 이동하지 않고 가운데 클릭은 클릭처럼 엽니다. 설정 대화상자가 열린 동안 `Ctrl+E`·`Ctrl+S`를 무시합니다. 전체 재작성 확인창은 한국어 버튼과 안전한 기본값, 사유를 표시합니다. 텍스트로 열기 실패와 업데이트 설치 지연을 알립니다.
- **CI**: clippy 검사(`-D warnings`), 중복 실행 취소, 작업 시간 제한을 추가했습니다.
- **로컬 검증**: JavaScript 695개 통과·2개 건너뜀, Rust 53개 통과와 타입 검사·빌드·번들 검사·clippy를 확인했습니다. Rust 검증은 설치된 1.96.1 툴체인으로 실행했습니다.
- **한계**: Markdown도 10 MiB까지 엽니다. CP949 선택은 CSV에만 제공하고, 전체 재작성 사유 문구는 영문입니다. 이번 변경은 자동 테스트로 검증했고, 현재 코드로 빌드한 앱의 수동 확인과 Linux 물리 데스크톱·Wayland는 미검증입니다.
