# v0.9.0 — 텍스트·코드 편집과 Markdown 글꼴 설정

일반 텍스트와 코드 파일을 읽고 안전하게 편집할 수 있습니다. 제목 표시줄의 설정 화면에서 Markdown 글꼴과 크기를 바꿀 수 있습니다.

- **텍스트·코드**: TXT/LOG/INI/TOML, C/C++, Python, Rust, JS/TS 등 주요 확장자를 지원합니다. 미등록 형식과 확장자 없는 파일은 `Ctrl+Shift+O`로 텍스트로 열 수 있습니다. 파일 내용은 실행하지 않습니다.
- **원문과 저장 보호**: UTF-8과 BOM이 있는 UTF-16의 인코딩·BOM·줄바꿈을 보존합니다. 읽기·편집을 분리하고 검색과 복사, 저장 및 복사본 저장을 제공합니다. 외부 수정 충돌과 저장 오류 시 편집 내용을 유지하며 미저장 닫기·업데이트 보호를 적용합니다.
- **심플한 화면**: 본문 위에 작은 메뉴와 읽기·편집 전환만 둡니다. 저장·다시 읽기는 파일 메뉴에, 검색은 필요할 때만 여는 검색창에, 인코딩은 설정 화면에 둡니다.
- **CP949**: 설정에서 현재 파일의 인코딩을 직접 선택해 한국어 파일을 열고 저장할 수 있습니다. 표현할 수 없는 문자는 저장을 거부해 원문과 편집 내용을 보호합니다.
- **Markdown 설정**: 제목줄 설정 버튼 또는 `Ctrl+,`에서 시스템·명조·고정폭 글꼴과 12~24px 크기를 선택합니다. 읽기·편집 모드에 함께 적용하고 설정을 기억해 열린 창에도 동기화합니다. 문서 원문은 바꾸지 않습니다.
- **제한**: 텍스트 파일과 편집 결과는 10 MiB까지 지원합니다. 혼합 줄바꿈은 읽기 전용이며 바이너리·잘못된 인코딩은 거부합니다. 코드 구문 강조·자동 완성과 대용량 로그 스트리밍은 제공하지 않습니다. 다른 프로세스의 저장 검증·교체 사이 경쟁을 완전히 제거하지는 못합니다.
- **검증**: 필수 5종 통과(JS 538 통과/2 건너뜀, Rust 50 통과). Windows 분리 WebView에서 검색·UTF/CP949 저장·충돌 복사본·오류 보호·Markdown 읽기/편집·다중 창 설정 및 앱 재시작 후 설정 복원을 확인했습니다. 컴퓨터 조작으로 실제 파일 열기와 미저장 닫기 취소를 확인했습니다. 복사본 저장 대화상자는 시험 경로로 대체했습니다. Linux GUI와 설치본 파일 연결·실제 자동 업데이트는 미검증입니다.
