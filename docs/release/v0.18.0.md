# v0.18.0 — 창 너비를 따르는 Markdown 본문과 섹션 접기

Markdown 본문이 이제 창 폭을 따라 넓어집니다. 좌우에는 일정한 여백만 남습니다. 읽기 모드에서는 제목마다 섹션을 접고 펼칠 수 있습니다.

- **창 너비 본문**: 기본 본문 폭이 "창 너비"가 되었습니다. 창을 넓히면 줄도 함께 길어지고, 좌우 여백은 창 크기에 따라 36~64px 사이로 맞춰집니다. 편집 모드도 같은 폭을 씁니다. 설정(`Ctrl+,`) > 본문 폭에서 좁게 · 보통 · 넓게를 고를 수 있습니다.
- **섹션 접기**: 읽기 모드에서 제목에 마우스를 올리면 왼쪽 여백에 접기 버튼이 나타납니다. 누르면 다음 같은 단계 또는 상위 제목 전까지 접히고, 제목 옆에 ▸와 "…"가 남습니다. 키보드 Tab으로도 버튼에 갈 수 있습니다. 안쪽 섹션을 접어 둔 채 바깥 섹션을 접었다 펴도 안쪽은 접힌 채로 남습니다. 보기 메뉴의 "모든 섹션 접기 · 펼치기"로 한 번에 바꿀 수 있습니다.
- **접힌 곳으로 이동**: 목차 클릭, 찾기(`Ctrl+F`) 결과, 문서 안 링크가 접힌 섹션 안을 가리키면 감싼 섹션을 자동으로 펼친 뒤 이동합니다. 파일이 바깥에서 바뀌어 다시 그려져도 접은 상태는 유지됩니다.
- **로컬 검증**: JavaScript 847개 통과 · 2개 건너뜀과 타입 검사 · lint · 빌드 · 번들 검사를 확인했습니다. 실제 앱(Windows, 1900px 창)에서 본문이 창 폭을 채우는 것, 접기 · 펼치기, 편집 모드 폭을 확인했습니다. GitHub CI도 통과했습니다. 이번 변경은 설치 · 파일 연결과 무관해 desktop 설치 시험은 다시 돌리지 않았습니다.
- **한계**: 접은 상태는 창을 닫으면 기억하지 않습니다. 접기는 본문 바로 아래의 제목에만 붙고, 인용문 · `<details>` 안의 제목에는 붙지 않습니다. 예전 기본값 "보통"으로 저장돼 있던 설정은 직접 고른 값과 구분할 수 없어 창 너비로 바뀝니다. "좁게" · "넓게"를 고른 설정은 그대로입니다.
