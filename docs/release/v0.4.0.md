# v0.4.0 — 이미지와 데이터 파일을 가볍게 보고 편집

이미지와 JSON/YAML/CSV를 열고 편집할 수 있으며, 3D 조작과 점군 패널을 개선했습니다.

- **이미지**: PNG/JPEG/WebP/BMP/GIF/SVG 폴더 탐색·썸네일과 회전·반전·자르기, 원본을 보존하는 별도 PNG 저장을 지원합니다. GIF/SVG 편집 결과는 정적 이미지입니다.
- **데이터**: JSON/YAML 트리·원문 편집과 CSV 표·셀 편집을 추가했습니다. CSV의 수정하지 않은 셀과 텍스트 인코딩·줄바꿈을 보존합니다.
- **저장 보호**: 외부 변경 시 편집 내용을 유지하고 충돌을 알립니다. 같은 앱의 동시 저장은 원본 확인 후 직렬화합니다.
- **3D 조작**: Arcball과 Fly를 지원하고 장면 트리와 점군 도구를 오른쪽 패널에 모았습니다. HTML 공유에도 카메라 방향과 조작 모드를 담습니다.

데이터 파일은 10 MiB, CSV는 100,000셀, 이미지는 100 MiB·5천만 픽셀까지 지원합니다. 다른 프로그램이 저장 확인과 교체 사이에 쓰는 경쟁은 완전히 배제하지 못합니다. PDF는 후속 버전에서 다룹니다.
