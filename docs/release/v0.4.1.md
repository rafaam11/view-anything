# v0.4.1 — 저장 충돌 보호와 큰 CSV 표시 개선

외부 파일 변경으로 편집 내용을 잃지 않도록 복구 경로를 추가하고, 큰 CSV의 화면 반응성을 개선했습니다.

- **충돌 복구**: Markdown·JSON/YAML·CSV에서 원본이 변경되거나 삭제되면 편집 내용을 유지하고 다른 이름으로 복사본을 저장할 수 있습니다. 기존 복사본은 덮어쓰지 않습니다.
- **CSV 성능**: 표를 100행씩 표시하고 편집한 셀은 저장 시 반영해 큰 파일의 화면 전환 부담을 줄였습니다.
- **검증**: Windows 테스트 WebView에서 충돌 복구와 Fly 키보드 이동을 확인하고, 합성 CSV·JSON·이미지로 현재 한도 근처의 성능을 측정했습니다.

외부 프로그램이 저장 검증과 교체 사이에 쓰는 경쟁은 완전히 배제할 수 없습니다. 하드 링크를 지원하지 않는 파일시스템에서는 복사본 저장이 안전하게 실패합니다. Linux GUI와 설치본의 실제 자동 업데이트는 직접 검증하지 않았습니다.
