# v0.17.0 — Office 없이 여는 Word · PowerPoint · Excel 뷰어

Office가 설치되지 않은 PC에서도 `.docx` · `.pptx` · `.xlsx`를 읽기 전용으로 엽니다. 원본 레이아웃을 최대한 그대로 그리고, 화면 배치와 조작은 Office 365를 따릅니다. 왼쪽에 탐색 창 · 썸네일, 가운데에 문서, 아래에 확대 슬라이더가 있는 상태줄을 두었습니다. 렌더러는 해당 형식을 열 때만 불러오므로 시작 속도는 그대로입니다.

- **Word**: 글꼴 · 표 · 이미지 · 머리글/바닥글 · 각주까지 페이지 모양 그대로 보여 줍니다. 왼쪽 **탐색 창**에 제목 목록이 나오며, 현재 위치를 강조하고 클릭하면 그 제목으로 이동합니다. `Ctrl+F`로 찾을 수 있고, 상태줄에 페이지 · 단어 수가 나옵니다. 웹 · 메일 링크는 기본 브라우저로 열고, 문서 안 책갈피는 그 위치로 이동하며, 그 밖의 링크는 열지 않습니다.
- **PowerPoint**: 왼쪽 **슬라이드 썸네일**, 가운데 슬라이드, 아래 **발표자 노트**로 보여 줍니다. 도형 · 표 · 차트 · 이미지를 그립니다. `F5`(처음부터) · `Shift+F5`(현재부터)로 전체 화면 **슬라이드 쇼**를 하며, 클릭 · 방향키 · 휠로 넘기고 `Esc`로 끝냅니다. 외부 링크 그림 · 미디어는 불러오지 않습니다.
- **Excel**: **이름 상자 · 수식 입력줄**과 셀 · 범위 선택을 지원합니다. 드래그, 행 · 열 머리글, 방향키 · `Shift` · `Ctrl`+방향키 · `Ctrl+Home` · `Ctrl+A`를 쓸 수 있습니다. 선택 범위의 평균 · 개수 · 합계를 상태줄에 보여 주고, `Ctrl+C`로 표 형식 그대로 복사합니다. 숫자 · 날짜 서식, 글꼴 · 채우기 · 테두리 · 정렬, 열 너비 · 행 높이, 병합 셀, 틀 고정, 시트 탭을 재현합니다. 200행 × 50열 단위로 넘기며 시트당 100만 셀까지 표시합니다.
- **공통 화면**: 상태줄 확대 슬라이더(10~400%, 가운데 100%)와 `Ctrl+휠` · `Ctrl+=` · `Ctrl+-` · `Ctrl+0`(창에 맞춤)을 씁니다. Word 파랑 · Excel 초록 · PowerPoint 주황 강조색은 다크 · 라이트 테마를 모두 따르고, 문서 자체는 Office처럼 흰 종이로 보입니다. 리본은 두지 않고 다른 뷰어와 같은 메뉴를 씁니다.
- **파일 연결**: 설치 프로그램은 세 확장자를 **연결 프로그램** 목록에만 올리고, 기본 앱은 바꾸지 않습니다. 열기 대화상자에도 "Office 문서" 형식을 추가했습니다.
- **수정 — 스크립트 실행이 막히던 문제**: 이전 버전 설치 프로그램이 `.bat` `.cmd` `.ps1` `.js` `.py` `.sh` 등의 기본 연결을 가져가서, 더블클릭하면 실행되지 않고 "연결 프로그램 선택" 창이 떴습니다. 이제 설치 프로그램은 어떤 형식의 기본 앱도 바꾸지 않고 연결 프로그램 목록에만 올립니다. 실행되는 형식은 목록에도 올리지 않고 우클릭 메뉴의 **View Anything으로 보기**로만 제공합니다. 설치·업데이트할 때 이전 버전이 실행 형식에 남긴 기본값과 연결 항목을 원래대로 되돌리고, 제거하면 레지스트리 흔적을 남기지 않습니다.
- **안전**: 100 MiB까지 엽니다. 압축을 풀기 전에 항목 수(2만)와 해제 크기(1 GiB)를 검사합니다. 암호로 보호된 문서와 구형 바이너리(`.doc` `.ppt` `.xls`)는 이유를 알리고 열지 않습니다. Word 문서 안의 원시 HTML 조각(altChunk)은 표시하지 않습니다.
- **로컬 검증**: JavaScript 843개 통과 · 2개 건너뜀, Rust 65개 통과와 타입 검사 · lint · 빌드 · 번들 검사 · clippy(1.99.0)를 확인했습니다. 진입 청크는 46 KiB이고, PowerPoint 렌더러 청크는 차트 라이브러리를 포함해 약 1.3 MB입니다(pptx를 열 때만 불러옴). 합성 docx · pptx · xlsx를 실제 앱(Windows, WebView2)에서 열어 탐색 창 이동, 범위 선택 · 상태줄 합계, 썸네일 · 노트, F5 슬라이드 쇼 진입 · 종료를 확인했습니다. 로컬 NSIS 빌드로 Office 연결 분기가 컴파일되는 것도 확인했습니다. GitHub **desktop** workflow에서 Windows 설치 시 기존 `.docx` 기본 앱이 바뀌지 않고 연결 프로그램에만 등록되는 것, 등록된 연결로 DOCX가 열리는 것, Linux deb/AppImage의 실제 WebKitGTK에서 DOCX 페이지가 그려지는 것을 통과했습니다. 같은 Windows 시험에서 0.16이 남긴 손상(`.bat` `.cmd` `.ps1` 기본값과 빈·실제 backup, Classes와 Explorer FileExts의 연결 항목, `*` 값)을 미리 심은 뒤 설치와 서명 업데이트 후 모두 수리되는 것, 스크립트가 우클릭 동사로만 제공되는 것, `.bat`를 더블클릭과 같은 방식(클래스 없는 ShellExecuteEx)으로 열면 cmd로 실행되는 것, 제거 후 `HKCU\Software\Classes`와 FileExts에 앱 흔적이 남지 않는 것을 확인했습니다. 이 PC에서 직접 설치해 보지는 않았습니다.
- **한계**: Excel 수식은 파일에 저장된 결과만 보여 주고 다시 계산하지 않습니다. 결과 없이 저장된 수식은 빈칸입니다. 매크로 · 피벗 · 차트 시트 · 조건부 서식 · 셀 메모는 표시하지 않습니다. Word의 변경 내용 추적 · 메모는 숨기며, PowerPoint의 애니메이션 · 화면 전환 · 동영상 재생은 지원하지 않습니다. 렌더링은 Office와 픽셀 단위로 같지 않고, PC에 없는 글꼴은 다른 글꼴로 대체됩니다. 압축 해제 전 검사는 파일이 밝힌 크기를 기준으로 하므로, 크기를 속인 파일은 메모리를 많이 쓸 수 있습니다.
