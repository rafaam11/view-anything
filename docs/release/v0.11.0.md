# v0.11.0 — 이미지 편집 이력과 안전한 설치·업데이트

이미지 실행 취소와 폴더 새로고침을 추가하고, 텍스트 표시 설정을 현재 뷰어에 맞게 정리했습니다. 업데이트 중 미저장 작업 보호와 Windows 파일 연결의 복원도 보완했습니다.

- **이미지 이력**: 회전·반전·자르기를 최대 20회 실행 취소하고 다시 실행합니다. `Ctrl+Z`, `Ctrl+Y`, `Ctrl+Shift+Z`를 지원하며 저장한 상태로 돌아오면 미저장 표시도 해제됩니다. 편집 모드에서만 도구를 표시합니다.
- **폴더 갱신과 복구**: 창 활성화·F5·저장 후 이미지 목록을 갱신합니다. 원본 파일이나 폴더가 삭제되거나 다음 이미지가 손상돼도 현재 표시와 편집을 유지하고, 다른 PNG로 복구 저장할 수 있습니다. 삭제된 원본 경로의 재생성과 덮어쓰기는 차단합니다.
- **간결한 설정**: 현재 뷰어에 필요한 항목만 표시합니다. 텍스트 글꼴·크기·자동 줄바꿈은 설정에서 변경하고 여러 창과 재시작 후에도 유지합니다. 인코딩은 현재 파일에만 적용하며 본문과 미저장 편집을 보존합니다.
- **긴 텍스트 검색**: 검색 위치의 줄바꿈 계산을 나눠 실행하고, 취소하거나 본문·설정을 변경하면 지연된 스크롤을 중단합니다. 파일과 편집 결과의 10 MiB 한도는 유지합니다.
- **업데이트 보호**: 모든 창에서 단축키보다 먼저 입력을 잠가 확인 대화상자 안의 Ctrl+S, 다른 창의 저장·열기 요청까지 차단합니다. 취소하면 기존 편집과 설정 대화상자의 상태를 복원합니다.
- **Windows 파일 연결**: 앱 전용 클래스명으로 다른 앱의 전역 클래스 충돌을 줄입니다. 업데이트가 최초 연결 백업을 덮어쓰지 않으며 제거 시 복원합니다. 설치 후 다른 앱으로 바꾼 연결은 업데이트·제거 시 유지합니다. 구버전 클래스는 실행 명령이 이 앱과 같을 때만 백업을 이관하며, 이미 소실된 과거 연결 정보는 복원할 수 없습니다.
- **자동 검증**: 필수 5종 통과(JS 567 통과/2 건너뜀, Rust 51 통과). 일반 Windows/Linux CI와 별도의 일회용 패키지 회귀를 실행했습니다. 초기 번들과 Markdown에 무거운 뷰어를 넣지 않는 검사도 통과했습니다.
- **실제 패키지 GUI**: Windows NSIS 설치→임시 키로 서명한 실제 업데이트→자동 시작→제거와 파일 연결 복원·미저장 다중 창 보호를 검증했습니다. Ubuntu 22.04의 Xvfb/Openbox/WebKitGTK에서 deb·AppImage 각각 TXT 안전 저장·설정, 이미지 undo/redo·X11 PNG 클립보드, PDF 검색, PCD/STL 표시, 실제 GTK 저장창의 HTML 내보내기와 재열기를 확인했습니다. 본문 자동 조작과 네이티브 저장·클립보드 검증은 [검증 기록](https://github.com/rafaam11/view-anything/blob/v0.11.0/docs/superpowers/plans/2026-10-29-desktop-checklist.md)에 구분했습니다.
- **한계**: 폴더 갱신은 실시간 감시가 아니며 썸네일은 1,000개까지 표시합니다. 이미지 이력은 파일 전환·원본 재읽기 시 초기화하고 GIF/SVG 편집은 정적 결과입니다. 큰 TXT의 최초 전체 레이아웃 지연, 100 MiB 로그 스트리밍과 물리 데스크톱·Wayland 검증은 후속 범위입니다.
