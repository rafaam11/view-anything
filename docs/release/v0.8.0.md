# v0.8.0 — 점군 정합 품질과 실행 취소

점군 정합 결과를 더 잘 평가하고 필터와 정합을 적용한 순서대로 되돌릴 수 있습니다.

- **정합 품질**: 대응점 수·비율, RMSE, 반복 횟수와 수렴 여부를 표시합니다. 작은 좌표에서도 퇴화와 수렴을 상대적인 크기로 판단합니다.
- **실행 취소**: 정합과 필터를 섞어 적용해도 최대 20단계까지 적용 순서대로 실행 취소·다시 실행할 수 있습니다. 별도 저장과 미저장 보호에도 정합 상태가 반영됩니다.
- **표본 선택**: 점군별 최대 1만·5만·10만 점을 선택합니다. 기본값은 10만 점이며 원본 점 합계·메모리 제한은 유지합니다.
- **조사와 검증**: COPC·LAS 파형의 보존 과제와 ICP 합성 성능을 문서화했습니다. Windows 분리 WebView에서 정합·필터 실행 취소/재실행·저장과 100만 점 장면의 표본 선택을 확인했습니다.

ICP는 초기 위치와 표본에 영향을 받으므로 수렴 표시만으로 정확한 정합을 보장하지 않습니다. COPC·파형은 아직 지원하지 않습니다. Linux 실제 GUI와 설치본 파일 연결·자동 업데이트는 직접 확인하지 않았습니다.
