# v0.2.0 — 3D 뷰어와 HTML 내보내기

STEP·IGES·STL·OBJ·PLY·glTF·GLB 파일을 더블클릭하면 바로 열리는 3D 뷰어가 추가되었습니다. 여러 파일을 끌어다 놓아 한 장면에 모아 볼 수 있고, 장면을 앱 없이도 열리는 HTML 파일 하나로 내보낼 수 있습니다. 수백 MB 파일도 UI가 멈추지 않도록 읽기, 파싱, 엣지 계산을 백그라운드에서 처리합니다.

- **지원 형식**: STL(바이너리·ASCII), OBJ, PLY(메시·점), glTF/GLB(텍스처 포함), STEP/STP, IGES/IGS. 확장자는 대소문자를 가리지 않고, 설치 시 파일 연결이 등록됩니다.
- **STEP/IGES**: OpenCascade(occt-import-js, wasm)로 백그라운드에서 읽고, 단위는 mm로 통일합니다. 파트 이름과 어셈블리 계층이 장면 트리에 그대로 나옵니다. 큰 파일 변환이 메모리 부족 등으로 실패하면 "정밀도를 낮춰 다시 시도"를 제안합니다.
- **Meshmixer식 조작**: 왼쪽 드래그 회전, 오른쪽·가운데 드래그 이동, 휠은 커서 위치 기준 확대·축소입니다. F는 전체 맞춤, 1~7은 앞·뒤·좌·우·위·아래·등각 표준 뷰입니다. 아주 가까이 확대해도 면이 깨지지 않도록 최소 거리를 장면 크기에 맞춰 둡니다.
- **드롭과 열기 규칙**: 3D 창에 3D 파일을 놓으면 같은 장면에 추가(append)하고, 3D가 아닌 파일은 새 창으로 엽니다. Shift를 누른 채 놓으면 3D 파일도 새 창으로 엽니다. 빈 창에 여러 파일을 놓으면 첫 파일을 그 창에서 열고 나머지 3D 파일은 추가합니다. md 창은 기존처럼 항상 새 창입니다. 3D 창의 Ctrl+O와 파일 > 장면에 추가도 같은 규칙을 따릅니다.
- **장면 트리 패널**: 파일 아래 어셈블리 트리(STEP 파트, OBJ의 o/g, glTF 노드)를 보여줍니다. 노드마다 표시·숨김, 파일 단위 제거, 클릭 선택을 지원합니다. 큰 트리는 처음에 한 단계만 펼칩니다.
- **좌표계 프리셋**: 좌표 값은 파일 그대로 씁니다. 화면 기본값은 Z-up 오른손이고, Z-up 오른손(CATIA/NX/Creo/STEP), Y-up 오른손(glTF/Maya/SolidWorks), ROS REP-103, Y-up 왼손(Unity), Z-up 왼손(Unreal) 중에서 화면 좌표계를 고를 수 있습니다. 파일마다 원본 좌표계와 단위(mm, cm, m, inch)도 따로 지정할 수 있으며, 기본값은 "그대로"입니다.
- **표시 모드**: 솔리드, 와이어, 솔리드+엣지(30° 기준 엣지 선), X-ray.
- **치수와 커서 좌표**: 장면 전체나 선택한 객체의 bbox 크기와 삼각형 수를 보여줍니다. 커서 아래 표면 좌표는 화면 좌표계 기준으로 표시하고, 원본 좌표가 다르면 함께 표시합니다.
- **단면**: X/Y/Z 단면 슬라이더(화면 좌표계 기준).
- **HTML 내보내기**: 파일 > HTML로 내보내기(Ctrl+Shift+E)로 보이는 장면을 외부 요청 없는 단일 HTML 파일로 저장합니다. meshopt로 압축하고, 텍스처를 담으며, 내보낸 시점의 카메라·표시 여부·표시 모드·단면이 그대로 열립니다. 내보낸 파일에서도 트리, 표시 모드, 단면, 표준 뷰, 치수를 쓸 수 있습니다. 50MB를 넘으면 저장 전에 확인합니다.
- **메뉴바**: 3D 창 위쪽에 파일·보기 메뉴가 생겼습니다(Alt+F, Alt+V). 표시 모드와 단면은 보기 메뉴에 있습니다.
- **대용량 파일 성능**: 파일을 asset 프로토콜의 병렬 Range 요청으로 읽고 진행률을 표시합니다. 파싱은 워커에서 하며, GPU 업로드는 100만 삼각형 단위로 나눠 프레임마다 올리므로 로딩 중에도 창이 반응합니다. 150MB(삼각형 300만 개) 바이너리 STL의 파싱은 개발 PC에서 약 0.15초입니다. 엣지와 커서 좌표용 BVH도 워커에서 만들며, 엣지 계산은 three.js 기본 구현보다 약 12배 빠릅니다.
- **자동 업데이트**: (Task 10에서 추가 예정)
- **설치 파일 크기 증가**: STEP/IGES를 읽는 OpenCascade wasm(약 7.6MB)이 포함되어 v0.1.0보다 설치 파일이 커졌습니다. wasm은 STEP/IGES를 열 때만 로드하므로 md와 다른 3D 형식의 시작 속도에는 영향이 없습니다.
- **이번 버전에서 하지 않는 것**: 단면의 잘린 면 채우기(캡), 두 점 사이 거리 측정.
- **알려진 제한**
  - Linux에서는 OS가 Shift 상태를 알려주지 않아, 창에 포커스가 없을 때 Shift+드롭이 새 창으로 열리지 않을 수 있습니다(Windows는 항상 동작).
  - 장면의 삼각형이 500만 개를 넘으면 엣지 표시와 커서 좌표를 끕니다.
