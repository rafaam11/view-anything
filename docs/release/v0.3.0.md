# v0.3.0 — 포인트클라우드 정리·저장과 테마 전환

PCD/PLY 포인트클라우드를 기존 3D 장면에서 검사하고 영역 선택·필터로 정리할 수 있습니다. 원본 좌표와 사용자 정의 속성을 보존하며 다른 이름으로 저장합니다. 우측 상단에는 다크·라이트·시스템 테마 전환 버튼을 추가했습니다.

- **PCD/PLY**: PCD ASCII·binary·binary_compressed(LZF), PLY ASCII·little/big endian을 읽습니다. 점의 scalar/list 속성과 64bit 정수 값을 보존합니다. face가 있는 PLY는 기존 메시 뷰어로 열고, 지원하지 않는 비점 요소가 있으면 편집을 제한합니다. PCD 파일 연결도 등록합니다.
- **표시와 점 조회**: 원본 RGB·단색·높이·intensity 색상과 1~10px 점 크기(기본 2)를 지원합니다. GPU ID로 보이는 점을 선택해 원본 좌표·화면 좌표·속성을 조회합니다. 계산 좌표는 f64, 화면은 원점 이동한 f32이며 VIEWPOINT를 자동 적용하지 않습니다.
- **영역 선택**: 화면 좌표계 기준 3D 박스의 핸들/최소·최대 값으로 영역을 고르거나 화면 다각형으로 앞뒤를 관통해 선택합니다. 단면과 경계를 반영하고, 선택 부분 남기기·삭제가 가능합니다. Esc는 선택 입력을 취소합니다.
- **필터**: Voxel은 복셀 중심에 가장 가까운 원본점을 남깁니다(평균점 생성 아님). SOR은 정확 이웃 검색과 모표준편차를 사용하며 기본 k=20·배수 2입니다. 반경 필터 기본 최소 이웃은 자신을 제외한 5점입니다. 거리·복셀 크기는 원본 단위로 직접 입력합니다.
- **작업본 보호**: 필터·자르기는 미리보기 후 명시적으로 적용하거나 취소합니다. 최대 20회 실행 취소/다시 실행, 작업 취소, 미저장 파일 제거·창 닫기·업데이트 보호를 제공합니다. 화면 갱신에 실패하면 작업본을 유지한 채 재표시할 수 있습니다.
- **저장**: Ctrl+S 또는 다른 이름으로 저장을 사용합니다. 원본 덮어쓰기는 금지하며 기본 이름은 `_edited`입니다. PCD는 binary, PLY는 little endian으로 같은 형식에만 저장합니다. 기존 대상 교체는 확인 후 원자적으로 처리합니다. 변경 없는 organized PCD는 조직화를 유지하며 편집 후에는 HEIGHT=1이 됩니다. NaN/Inf 좌표는 표시·계산에서 제외하고, 정리를 적용하면 저장 결과에서도 제외됨을 안내합니다.
- **HTML 공유**: 현재 보이는 점·색상·크기를 단일 오프라인 HTML에 담습니다. 사용자 정의 원본 속성, 편집·PCD/PLY 저장 기능은 포함되지 않는 보기 전용 파일임을 먼저 안내합니다. 내보내는 동안 장면·클라우드 편집을 잠급니다.
- **테마와 창 제어**: 최소화 버튼 왼쪽의 버튼으로 다크 → 라이트 → 시스템 순서로 바꿉니다. 설정을 기억하고 열린 창에 동기화합니다. 커스텀 제목 표시줄은 최소화·최대화/복원·닫기와 미저장 확인을 지원합니다.
- **처리 한도**: 장면 원본 점 합계 1천만, 디코딩 2GiB/세션, 예상 작업 메모리 8GiB/앱입니다. 숨김·편집 후에도 원본은 메모리에 유지되므로 한도를 회수하려면 파일을 제거하세요. 실제 OS/GPU 메모리의 하드 상한은 아닙니다. 계산은 Rust 백그라운드에서 앱 전체 하나씩, 화면 전송은 25,000점 청크로 진행합니다.
- **실측 성능**: 개발 PC의 합성 1천만 XYZRGB+ring 점(180MB), Windows release WebView2에서 표시 3.9초, Voxel 미리보기 1.25초, SOR 9.13초, 반경 6.64초, 박스 선택 4.23초였습니다. 최대 JavaScript 작업 135ms, 취소 ACK 4ms, 앱과 자식 프로세스 private commit 피크 약 2.91GiB를 측정했습니다. 약 1초 간격 프로세스 표본이며 GPU 전용 메모리는 포함하지 않습니다. 모든 데이터 분포·장비의 성능을 보장하지 않습니다.
- **검증**: JS 테스트 488개·Rust 테스트 33개, 타입 검사·빌드·번들 격리 검사를 통과했습니다. Windows에서 저장/재열기 속성 보존·원본 보호·이력·취소·테마/창 제어를 확인했고, 네트워크 차단 Edge에서 HTML 공유를 확인했습니다. 세부 결과와 미확인 항목은 [체크리스트](https://github.com/rafaam11/view-anything/blob/v0.3.0/docs/superpowers/plans/2026-10-27-v0.3.0-manual-checklist.md)에 있습니다.
- **알려진 제한**: LAS/LAZ, ICP/RANSAC, PCD↔PLY 변환은 지원하지 않습니다. 이웃 검색 트리 생성 중의 취소는 라이브러리 호출이 반환된 뒤 반영됩니다. SOR/반경은 절댓값 1e150 초과 좌표를 거부하며, 화면 f32 범위를 넘는 데이터도 거부합니다. 점 정보는 최대 4096개 속성 값만 보여주지만 저장에는 전체를 보존합니다. Linux GUI·설치본 파일 연결·실제 자동 업데이트 완료·물리적 제목 표시줄 드래그/Snap은 수동 확인 항목이며 통과로 간주하지 않습니다.
