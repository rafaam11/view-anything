# v0.12.0 — Markdown 읽기 도구와 이미지 드래그 자르기

Markdown에 문서 내 찾기와 즉시 글자 크기 조절, 파일 변경 자동 반영을 추가했습니다. 이미지에서는 드래그로 자르기 영역을 지정하고, 왼쪽 회전·상하 반전과 파일 경로 복사를 사용할 수 있습니다.

- **Markdown 찾기**: 읽기 모드의 `Ctrl+F`로 본문을 찾고 `Enter`·`Shift+Enter`로 결과를 이동합니다. 인라인 서식에 나뉜 문장도 찾으며 Mermaid·수식 내부는 제외합니다. 편집 모드에서는 편집기의 찾기 동작을 유지합니다.
- **글자 크기와 본문 폭**: `Ctrl+휠`·`Ctrl+=`·`Ctrl+-`로 글자 크기를 바꾸고 `Ctrl+0`으로 기본값으로 돌아옵니다. 설정에서 본문 폭을 좁게·보통·넓게·창 너비로 선택하며 열린 Markdown 창과 다음 실행에도 적용합니다.
- **Markdown 읽기 장식**: 코드 블록에 복사 버튼을 제공하고 NOTE·TIP·IMPORTANT·WARNING·CAUTION 인용문을 알림 상자로 표시합니다. 읽기 화면의 장식은 원문 저장 방식에 영향을 주지 않습니다.
- **파일 변경 반영**: 창 재활성화 없이 약 1초 간격으로 외부 변경을 확인합니다. 스크롤 위치를 유지하고 Mermaid·이미지를 준비한 뒤 본문을 교체합니다. 편집·작업·본문 선택 중에는 갱신을 미루며 숨겨진 창은 감시를 쉽니다.
- **이미지 자르기와 변환**: 이미지 위에서 자르기 영역을 그리거나 이동하고 가장자리를 끌어 크기를 조절합니다. 숫자 입력도 지원하며 `Enter`로 적용하고 `Esc`로 취소합니다. 왼쪽 회전·상하 반전을 추가하고 기존 실행 취소·다시 실행과 연결했습니다.
- **이미지 정보와 복사**: 해상도·형식·용량, 투명 영역 체커보드와 400% 이상 픽셀 표시를 제공합니다. 편집 중에는 결과 해상도를 표시하며 체커보드는 저장·복사 결과에 포함하지 않습니다. `Ctrl+C`는 이미지를, `Ctrl+Shift+C`는 경로를 복사합니다.
- **전체 화면**: 모든 뷰어에서 `F11`로 전체 화면을 전환합니다. 이미지에서는 제목 표시줄·도구줄·상태줄·썸네일을 숨기며 `Esc`로도 해제합니다. 다른 파일을 열면 새 창을 만드는 정책은 유지합니다.
- **로컬 검증**: JavaScript 668개 통과·2개 건너뜀, Rust 52개 통과와 타입 검사·빌드·번들 검사를 확인했습니다. 현재 코드로 빌드한 Windows 앱에서 Markdown 찾기·글자 크기·본문 폭·코드 복사·자동 갱신, 이미지 자르기·변환·이력·복사·고배율 표시·전체 화면을 확인했습니다. 별도 PNG 저장 후 크기·투명도와 원본 SHA-256 보존도 확인했습니다.
- **한계**: Markdown 감시는 폴링 방식이며 쓰기 중인 파일은 안정된 뒤 다시 읽습니다. 이미지의 GIF/SVG 편집·복사는 정적 결과이고 원본 SVG에는 고배율 픽셀 표시를 적용하지 않습니다. Linux 물리 데스크톱·Wayland는 미검증입니다.
