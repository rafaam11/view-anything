# v0.7.0 — PDF 텍스트와 암호 문서 읽기

PDF에서 텍스트를 선택하고 검색 결과를 확인할 수 있으며 암호화된 문서를 열 수 있습니다.

- **텍스트와 검색**: 현재 페이지의 텍스트를 선택·복사하고 검색 결과를 강조하며 이전·다음 결과로 이동합니다.
- **암호 문서**: 암호 입력과 재입력·취소를 지원합니다. 암호는 저장하거나 로그에 남기지 않습니다.
- **검증**: Windows 분리 WebView에서 텍스트 선택, 여러 검색 결과 이동, 잘못된 암호 재입력·취소, 확대 및 빠른 페이지 전환을 확인했습니다.

PDF는 읽기 전용이며 100 MiB까지 지원합니다. Linux 실제 GUI와 설치본 파일 연결·자동 업데이트는 직접 확인하지 않았습니다.
