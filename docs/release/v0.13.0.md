# v0.13.0 — 현재 창을 항상 위에 표시

제목 표시줄에 창 고정 버튼을 추가했습니다. 다른 앱에 포커스를 두고 작업하면서 view-anything의 내용을 계속 참고할 수 있습니다.

- **창 고정**: 테마 버튼과 최소화 버튼 사이의 핀 버튼을 누르면 현재 창을 항상 위에 표시하고, 다시 누르면 해제합니다. 고정 상태는 핀 모양과 배경, 접근성 상태로 표시합니다.
- **창별 적용**: 고정은 누른 창에만 적용됩니다. 새 창이나 앱을 다시 열면 고정 해제로 시작합니다. 전체 화면으로 전환해도 고정 상태는 유지됩니다.
- **안정성**: 네이티브 창 상태를 조회해 표시하고, 변경 처리 중에는 연속 실행을 막습니다. 실패하면 기존 표시 상태를 유지하고 다시 시도할 수 있습니다.
- **로컬 검증**: JavaScript 672개 통과·2개 건너뜀, Rust 52개 통과와 타입 검사·빌드·번들 검사를 확인했습니다. Rust 검증은 설치된 1.93.1 툴체인으로 실행했습니다.
- **한계**: 다른 앱의 전체 화면 위에서 실제로 겹쳐 표시되는 동작과 Linux 물리 데스크톱·Wayland는 미검증입니다.
