# v0.6.0 — LAS/LAZ와 점군 정합

LAS/LAZ 점군을 열어 정리하고, 두 점군의 강체 정합을 미리 보고 별도 파일로 저장할 수 있습니다.

- **LAS/LAZ**: RGB·intensity 표시와 점 정보, 기존 점군 선택·필터 및 같은 형식으로 다른 이름 저장을 지원합니다. 좌표 외 점 속성·추가 바이트와 메타데이터를 보존합니다.
- **강체 ICP**: 현재 장면 위치를 기준으로 대상·기준 점군과 최대 대응 거리를 지정합니다. 결과를 미리 보고 적용하거나 취소하며, 원본을 덮어쓰지 않고 저장합니다. HTML 공유에도 적용된 장면 위치가 반영됩니다.
- **오류 보호**: 미리보기 중 내보내기와 변경을 막고, 저장 실패 시 임시 파일을 정리합니다. 저장 중 라이브러리 정리 오류로 앱이 종료되지 않도록 보완했습니다.
- **검증**: Windows 테스트 WebView에서 PCD·LAS·LAZ 정합과 오류·저장, 오프라인 HTML 열기를 확인했습니다. LAS/LAZ 결과는 독립 도구로 좌표와 색상·강도·GPS 시간·추가 속성을 대조했습니다.

ICP는 점군마다 최대 10만 점을 표본으로 사용하며 초기 위치와 대응 거리에 따라 결과가 달라집니다. 정합 적용은 필터 실행 취소 이력에 포함되지 않습니다. LAS/LAZ 좌표는 원본 스케일로 양자화하며 파형·COPC와 정밀도 보존이 어려운 파일은 지원하지 않습니다. 정수 XYZ PCD/PLY와 기본값이 아닌 센서 VIEWPOINT가 있는 PCD는 정합 저장을 지원하지 않습니다. Linux GUI와 설치본의 실제 파일 연결·자동 업데이트는 직접 확인하지 않았습니다.
