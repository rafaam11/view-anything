# v0.1.0 — Markdown 뷰어 첫 릴리스

탐색기에서 `.md` 파일을 더블클릭하면 바로 열리는 가벼운 Markdown 뷰어입니다. 읽기 모드에서 문서를 안전하게 보고, 필요할 때 Typora처럼 편집 모드로 전환해 고친 부분만 저장할 수 있습니다.

- **Markdown 읽기 모드**: GFM(표, 체크리스트, 취소선), 코드 하이라이트, KaTeX 수식, Mermaid 다이어그램, 목차, 상대경로 이미지, 문서 간 `.md` 링크 이동을 지원합니다.
- **안전한 HTML 렌더링**: 문서 안의 HTML 중 GitHub와 같은 안전한 부분(`<br>`, `<details>`/`<summary>`, `<sub>`/`<sup>`, `<kbd>`, `<img>`, `<a>`, 정렬 등)만 표시합니다. 스크립트, 이벤트 속성, `javascript:` 링크, `<iframe>`/`<object>`/`<embed>`/`<style>`/`<form>`은 제거됩니다.
- **Ctrl+O로 열기**: 파일 열기 대화상자로 문서를 엽니다. 빈 창에서는 그 창에, 문서가 열린 창에서는 새 창에 엽니다.
- **Typora식 편집 모드**: 읽기 화면에서 곧바로 WYSIWYG으로 편집합니다. 읽기 모드에서는 내용이 바뀌지 않습니다.
- **고친 블록만 저장**: 손대지 않은 블록은 원문 그대로 둡니다. frontmatter, 링크 정의, BOM, CRLF 줄바꿈이 보존됩니다.
- **외부 변경 보호**: 다른 프로그램(AI 에이전트 등)이 파일을 바꾼 뒤 저장하려 하면 덮어쓰기 전에 확인을 받습니다. 읽기 모드는 창으로 돌아올 때 바뀐 내용을 다시 읽습니다.
- **실행 파일 링크 차단**: 문서 속 링크로 `.exe`, `.bat`, `.ps1`, `.lnk` 같은 프로그램·스크립트를 실행하지 않습니다.
- **파일마다 새 창**: 파일을 열 때마다 독립된 창이 뜹니다.
- **파일 연결**: `.md`와 `.markdown` 확장자에 연결되어 더블클릭으로 열립니다.
- **테마**: 라이트/다크 테마를 지원합니다.
- **시작 속도**: 릴리스 빌드에서 실행부터 설계 문서(약 10KB) 전체 렌더링까지 약 0.55~0.62초(Windows 11, 3회 측정). 설치 파일 4.6MB.
- **배포 형식**: Windows(NSIS 설치 파일), Linux(deb, AppImage).
