# v0.1.0 — Markdown 뷰어 첫 릴리스

탐색기에서 `.md` 파일을 더블클릭하면 바로 열리는 가벼운 Markdown 뷰어입니다. 읽기 모드에서 문서를 안전하게 보고, 필요할 때 Typora처럼 편집 모드로 전환해 고친 부분만 저장할 수 있습니다.

- **Markdown 읽기 모드**: GFM(표, 체크리스트, 취소선), 코드 하이라이트, KaTeX 수식, Mermaid 다이어그램, 목차, 상대경로 이미지, 문서 간 `.md` 링크 이동을 지원합니다.
- **Typora식 편집 모드**: 읽기 화면에서 곧바로 WYSIWYG으로 편집합니다. 읽기 모드에서는 내용이 바뀌지 않습니다.
- **고친 블록만 저장**: 손대지 않은 블록은 원문 그대로 둡니다. frontmatter, 링크 정의, BOM, CRLF 줄바꿈이 보존됩니다.
- **파일마다 새 창**: 파일을 열 때마다 독립된 창이 뜹니다.
- **파일 연결**: `.md`와 `.markdown` 확장자에 연결되어 더블클릭으로 열립니다.
- **테마**: 라이트/다크 테마를 지원합니다.
- **시작 속도**: 콜드 스타트 측정값 TBD (Task 7에서 채움)
- **배포 형식**: Windows(NSIS 설치 파일), Linux(deb, AppImage).
