# v0.10.0 — 심플한 공통 UI와 이미지 조작 개선

뷰어의 메뉴와 버튼을 통일하고 이미지 화면을 아이콘 중심으로 정리했습니다. PNG·JPEG 등 이미지를 Ctrl+휠로 확대하고 Ctrl+C로 복사할 수 있습니다.

- **공통 UI**: Markdown·텍스트·JSON/YAML·CSV·이미지·PDF·3D의 메뉴 높이와 버튼·입력창 스타일을 통일했습니다. 파일명 중복 표시와 작업 버튼 나열을 줄이고 저장은 파일 메뉴, 검색은 필요할 때 여는 검색창에 둡니다.
- **이미지 조작**: Ctrl+휠로 포인터를 기준으로 확대·축소하고 드래그로 이동합니다. Ctrl+0으로 화면에 맞추고, 더블클릭으로 맞춤·100% 보기를 전환하며 좌우 화살표로 이전·다음 이미지를 엽니다.
- **이미지 복사**: Ctrl+C 또는 복사 아이콘으로 현재 이미지를 원본 해상도로 클립보드에 복사합니다. 편집했다면 편집 결과를 복사하며 확대 비율은 복사 결과에 영향을 주지 않습니다. PNG 전달과 디코딩·클립보드 쓰기는 raw IPC와 Rust 백그라운드 작업으로 처리합니다.
- **이미지 편집**: 편집 아이콘을 눌렀을 때 회전·반전·자르기 도구가 나타납니다. 자르기 좌표와 썸네일은 필요할 때만 표시하며 미저장 작업과 원본 보호를 유지합니다. 편집 결과는 파일 메뉴에서 별도 PNG로 저장합니다.
- **3D와 HTML 공유**: 공통 메뉴와 맞춤 아이콘을 앱과 내보낸 HTML이 함께 사용합니다. 표준 방향은 보기 메뉴와 1~7 단축키로 선택합니다.
- **안정성**: Windows 경로 구분자 차이로 이미지 탐색이 비활성화되는 문제와 창 크기 변경 중 재배치 경고를 수정했습니다. 복사 실패 시에도 편집 내용과 조작 가능한 상태를 유지합니다.
- **검증**: 필수 5종 통과(JS 543 통과/2 건너뜀, Rust 50 통과). 실제 Windows 분리 WebView에서 Ctrl+휠·드래그·미저장 보호·자르기 오류·공통 메뉴·저장·검색·반복 리사이즈·다크 모드와 오프라인 HTML을 확인했습니다. PNG·JPEG·회전 결과의 클립보드 크기와 픽셀을 OS API로 독립 검증했으며 컴퓨터 조작으로 복사 아이콘도 확인했습니다. 클립보드 실패 복구는 자동 테스트로 확인했습니다.
- **제한**: 애니메이션 편집·복사는 정적 프레임입니다. 이미지 한도는 기존 100 MiB·5천만 픽셀이며, 편집 실행 취소·폴더 목록 실시간 갱신은 이번 릴리스에 포함하지 않습니다. Linux GUI·설치본 파일 연결·실제 자동 업데이트 설치는 미검증입니다.
