# 2026-11 로드맵 후속 기록 (v0.13.1 · v0.14.0 · v0.15.0)

세 릴리스를 구현하며 계획과 다르게 정한 판단과, 리뷰에서 나왔지만 이번에 고치지 않은 작은 결함을 모은다. 실행 원장(`.superpowers/sdd/`, git 무시)을 지우기 전에 옮긴 기록이다. 계획 문서는 같은 폴더의 `2026-11-06-v0.13.1-stability.md`, `2026-11-06-v0.14.0-pointcloud-accuracy.md`, `2026-11-06-v0.15.0-usability.md`다.

## 보류한 결함 (다음 패치 후보)

우선순위가 높은 것부터 적는다.

- **최근 파일의 네트워크 경로 멈춤** (v0.15.0): Rust `path_exists`가 동기 명령이라 연결이 끊긴 NAS·매핑 드라이브 항목을 누르면 SMB 시간 초과까지 모든 창이 멈춘다. 접근 불가도 "삭제됨"으로 보고 목록에서 뺀다. `async` + `spawn_blocking`으로 바꾸고 `try_exists`의 오류와 NotFound를 구분한다. Markdown 링크도 같은 명령을 쓴다.
- **강조 오버레이의 Linux 실기기 확인** (v0.15.0): 정렬은 Windows(Chromium)에서만 측정했다. WebKitGTK에서 긴 파일 끝까지 스크롤, 줄바꿈 끔 상태의 가로 끝, 한글 IME 조합 중 표시를 확인한다.
- **텍스트로 연 최근 항목** (v0.15.0): 다시 열 때 확장자로 뷰어를 고른다. 지원하지 않는 확장자는 "지원하지 않는 형식" 화면이 뜬다. 모드를 함께 저장하거나 미지원 확장자는 텍스트로 연다.
- **10 MiB 넘는 Markdown** (v0.13.1): 감시가 1초마다 stat만 하고 화면이 갱신되지 않는 이유를 알리지 않는다. 편집으로 10 MiB를 넘기면 저장 때 충돌 메시지가 뜬다.
- **재작성 확인창의 사유** (v0.13.1): `SpliceError`의 영문 내부 문구가 그대로 보인다.
- **LAS 겹침 점** (v0.14.0): vendor `las`가 원시 class 12를 class 1과 겹침 비트로 바꿔, 형식 0~5의 겹침 점이 "12 예약(겹침)" 색으로 칠해지지 않는다.
- **명령줄 URI 세부** (v0.15.0): `file://host/share`가 상대 경로가 된다. UTF-8이 아닌 파일명은 손실 디코딩된다. `file:/x` 형식은 받지 않는다. `C:/x`와 `C:\x`가 최근 목록에서 다른 항목이 된다.
- **PNG 저장 세부** (v0.15.0): 기본 이름 `<모델>.png`가 같은 이름의 텍스처와 겹칠 수 있다. 진행 중 가드가 없고 축 라벨(DOM)이 빠진다. 내보낸 HTML의 다운로드는 클릭 직후 URL을 해제해 오래된 Safari·Firefox에서 실패할 수 있다.
- **화면 세부** (v0.15.0): 파일 메뉴의 최근 항목이 말줄임 대신 잘린다. "목록 지우기" 뒤 포커스가 body로 빠진다. 강조 한도 안내는 "1 MiB"라고 쓰지만 실제는 100만 자다.
- **코드 정리** (v0.13.1·v0.14.0·v0.15.0): `watchFile` 첫 라운드는 mount 직후 파일을 한 번 더 읽는다. 실패 화면의 "텍스트로 열기"는 텍스트로도 열 수 없는 경우에도 나온다. 벤치 예제의 `#![allow(dead_code)]`가 크레이트 전체에 걸린다. `check-bundle` 예산은 청크 파일 하나만 재고, 매니페스트에 없는 뷰어는 조용히 건너뛴다. `session.rs`의 안전망 주석은 `busy` 직렬화와 맞지 않는다. `cloud_request`의 장면 여유 계산에는 직접 테스트가 없다. `savePng`가 `exportHtml`과 그 JSDoc 사이에 있다. 빈 창 목록의 변경 구독은 해제하지 않는다.

## 계획과 다르게 정한 판단

- **커밋 방식**: worktree 없이 main에 바로 커밋했다(AGENTS.md 규칙). 커밋마다 검증을 모두 돌렸다.
- **Rust 툴체인**: 로컬 기본 1.88은 의존성이 거부한다. v0.13.1 태그 뒤 CI가 최신 stable(1.99)의 새 clippy 규칙으로 실패해, main에서 고치고 CI를 1.99.0으로 고정했다. 이미 푸시한 태그는 옮기지 않았으므로 v0.13.1 태그 커밋의 CI는 실패로 남는다(릴리스 빌드는 성공).
- **CSV 제어 문자** (v0.13.1): CSV도 텍스트 뷰어와 같은 바이너리 판정을 쓴다. VT와 SUB는 리뷰 뒤 허용했다.
- **권한 복사** (v0.13.1): 대상 권한 복사는 실패해도 저장을 계속한다(chmod를 거부하는 마운트). 이 경우는 단위 테스트로 재현할 수 없어 기존 저장 테스트로만 확인했다.
- **기존 clippy 지적 정리** (v0.13.1): CI에 clippy를 넣으며 기존 지적 7건을 고치고, 벤치 예제에는 `dead_code` 허용을 두었다. `cargo fmt --check`는 무관한 차이가 47곳이라 CI에 넣지 않았다.
- **번들 예산** (v0.14.0): Markdown 청크 예산을 사양의 300 kB 대신 800 KiB로 두었다. 사양 수치는 오래된 다이어그램 값이었고 실제 청크는 708 KiB다. 시작 속도는 진입 청크 60 KiB 예산이 지킨다.
- **분류 팔레트** (v0.14.0): 계획은 0~18이었지만 사양대로 0~22와 "그 외" 줄로 넓혔다.
- **최근 파일 메뉴** (v0.15.0): 메뉴 블록 안 버튼은 메뉴를 닫지 않으므로 닫기 콜백을 받는다. 스타일은 빈 창에서도 로드되는 `chrome.css`에 둔다.
- **구문 강조** (v0.15.0): 입력 중에는 색을 끄고 150 ms 뒤 다시 칠한다(오래된 레이어가 새 글자를 가리지 않게). 20만 자를 넘는 편집은 저장할 때까지 기본 색이다. 번들 검사 표지는 `registerLanguage`가 아니라 `highlightAuto`다(뷰어가 직접 부르는 이름이라 오탐).
- **스크린샷 모듈** (v0.15.0): 캡처와 다운로드는 Tauri 없는 `src/three/core/snapshot.ts`에 두어 WebGL 없이 테스트하고 HTML 런타임과 함께 쓴다. 빈 장면도 저장할 수 있다.
- **lint** (v0.15.0): Biome 권장 규칙 가운데 코드 스타일과 충돌하는 규칙은 끄고 정확성 규칙만 둔다. ES2020 lib 때문에 `Object.hasOwn` 대신 기존 `hasOwnProperty` 호출을 유지했다. `DocumentIO.write`의 반환형은 `Promise<boolean | undefined>`다.
- **리뷰어가 범위 밖으로 둔 것**: CP949는 CSV에만, Markdown 10 MiB 상한, 거친 mtime 파일시스템의 같은 길이 변경, 원자적 교체의 소유자·그룹, 내보낸 HTML의 분류 범례 없음, PLY/PCD 16비트 색 포화, append만 한 3D 파일은 최근 목록에 넣지 않음, 경로의 localStorage 저장, 부분 장면 PNG를 그대로 받아들였다.
