# v0.1.0 수동 확인 체크리스트 (Task 7)

자동 테스트(vitest 120개, cargo 8개)로는 확인할 수 없는 GUI·설치 항목이다. 모두 통과하면 릴리스 노트의 콜드 스타트 값을 채우고 `v0.1.0` 태그를 단다.

## 1. 설치와 파일 연결
- [ ] `npm run tauri build -- --bundles nsis`를 실행하고, 만든 NSIS로 설치한다(SmartScreen 경고는 "추가 정보 → 실행").
- [ ] `.md`의 "연결 프로그램"에 view-anything이 있는지 확인하고 기본 앱으로 지정한다. 그다음 더블클릭하면 열리는지 본다.
- [ ] 한글과 공백이 들어간 경로(예: `D:\문서 폴더\a b.md`)의 파일도 더블클릭으로 열리는지 확인한다.
- [ ] 콜드 스타트 시간(더블클릭부터 본문이 보일 때까지)을 측정해 `docs/release/v0.1.0.md`의 TBD를 채운다. md viewer chunk가 714 kB이므로 그 영향도 함께 본다.
- [ ] 다른 md를 하나 더 더블클릭하면 같은 프로세스에서 새 창으로 뜨는지 본다. 파일 없이 다시 실행하면 최근 창이 앞으로 오는지 본다.

## 2. 읽기 모드
- [ ] `tests/fixtures/sample.md`: 표, 코드 하이라이트, KaTeX, mermaid(라이트/다크 전환 포함), 목차, `그림 1.png`가 정상으로 보이는지 확인한다.
- [ ] raw HTML(`<details>`, `<kbd>`, `<sub>`, 표 안의 `<br>`, `<img width>`)은 보이고, `<script>`, `onerror`, `javascript:`, `<iframe>`은 아무 동작도 하지 않는지 확인한다. DevTools 콘솔에 CSP 위반이 없어야 한다.
- [ ] 링크
  - md 링크는 같은 창에서 열린다. `#앵커`와 각주로도 이동한다.
  - `.cpp`, `.png`, 폴더 링크는 기본 앱이나 탐색기로 열린다.
  - `.exe`, `.py`, `.lnk` 링크는 안내만 뜬다.
  - 없는 파일로 가는 링크도 안내만 뜨고, 보던 문서는 그대로 남는다.
- [ ] 창 제목이 파일 이름이다(같은 창에서 이동하거나 빈 창에 드롭한 뒤에도).
- [ ] 빈 창: 안내 문구 "파일을 끌어다 놓거나 Ctrl+O"가 보이고, 드롭이나 Ctrl+O로 파일이 열린다. 문서 창에서 Ctrl+O를 누르면 새 창으로 열린다.
- [ ] 테마: Ctrl+Shift+T로 바뀌고, 첫 화면이 깜빡이지 않는다.

## 3. 편집 모드와 저장
- [ ] sample.md에서 Ctrl+E → 문단 하나 수정 → 제목에 `●`가 붙는다 → Ctrl+S → `git diff`에 그 문단만 나온다. 확인 후 `git checkout tests/fixtures/sample.md`로 되돌린다.
- [ ] 이 저장소의 `AGENTS.md`와 설계 문서로 위 과정을 반복한다(frontmatter, 표, 참조 링크).
- [ ] mermaid와 수식 블록: 커서가 들어가면 원문이 보이고, 나가면 렌더링된 화면으로 돌아오는지 확인한다(Crepe 내부 DOM에 의존하는 부분).
- [ ] 수정한 뒤 창 X, Ctrl+E, 마우스 뒤로 버튼, Alt+←, F5를 각각 해 본다. 모두 확인 창이 뜨거나 막혀야 하고, 편집 내용이 조용히 사라지면 안 된다.
- [ ] 외부 변경
  - 읽기 모드로 연 상태에서 다른 편집기로 고친 뒤 창에 포커스하면 내용이 갱신된다.
  - 편집 중에 외부에서 고친 뒤 Ctrl+S를 누르면 "다른 프로그램이 파일을 변경했습니다" 확인 창이 뜬다. 기본 선택은 "저장 안 함"이고, Esc를 누르면 취소된다.
- [ ] CRLF·BOM 파일을 수정하고 저장해도 CRLF·BOM이 그대로 남는다. 줄바꿈이 섞인 파일이나 UTF-8이 아닌 파일은 편집 버튼이 비활성이다.

## 4. 보안
- [ ] 외부 UNC 이미지(`<img src="\\server\share\x.png">`)가 든 문서를 열어도 SMB 접속(445/tcp)이 일어나지 않는다.
