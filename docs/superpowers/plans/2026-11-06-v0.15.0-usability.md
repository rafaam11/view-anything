# v0.15.0 사용성 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 자주 쓰는 흐름을 줄인다. 최근 파일을 빈 창과 파일 메뉴에서 다시 열고, 텍스트·코드에 구문 강조를 입히며, 명령줄에서 텍스트로 열 수 있게 하고, 3D 화면을 PNG로 저장한다. PDF 테스트와 정확성 lint를 보강해 v0.15.0으로 릴리스한다.

**Architecture:** 최근 파일은 DOM 없는 `src/recent.ts`(localStorage + storage 이벤트)와 메뉴 블록 하나(`src/ui/recent-menu.ts`)로 만든다. 열기는 기존 라우팅(`src/main.ts`의 `openPaths`)을 새 창 이벤트 `va:open-path`로 재사용한다. 구문 강조는 텍스트 뷰어의 textarea를 그대로 두고 뒤에 같은 글꼴의 `<pre>`를 겹치는 방식이며, highlight.js core와 언어 모듈은 지연 import한다. CLI는 Rust `args.rs`의 파서만 바뀐다. 스크린샷은 공용 `Stage.snapshot()`을 앱과 HTML 런타임이 함께 쓴다.

**Tech Stack:** TypeScript vanilla, highlight.js 11(이미 의존성), three, Rust, vitest, Biome 2(lint 전용, 새 devDependency).

**Spec:** `C:\Users\uiop3\.claude\plans\ethereal-rolling-pizza.md`의 "번들 3" 절. 프로젝트 규칙은 `AGENTS.md`.

## Global Constraints

- 한국어 문서, 영어 식별자·커밋, Conventional Commits(scope 없음), main 직접 커밋.
- 시작 속도: 진입 청크(`check:bundle` 예산 60 KiB)에 highlight.js·three를 넣지 않는다. 텍스트 뷰어 청크도 highlight.js를 정적으로 참조하지 않는다.
