# v0.4.1 실사용 검증

- [x] Windows 테스트 WebView: JSON 편집 중 원본을 외부에서 변경한 뒤 저장을 거부하고, 편집 내용은 별도 복사본으로 저장했다. 원본과 복사본의 실제 파일 내용을 확인했다.
- [x] Windows 테스트 WebView: Fly 모드에서 W를 600ms 입력했을 때 캔버스 이미지가 바뀌었다. 다른 이동 키와 실제 물리 키보드는 별도 확인하지 않았다.
- [x] 합성 CSV 8,110,000바이트·10만 셀: 페이지 나누기 전 편집 전환이 60초를 초과했다. 변경 후 읽기 0.52초, 편집 전환 0.74초, 관찰된 최대 long task 295ms, JS heap 약 323MB였다. Windows WebView2 개발 실행에서 측정했으며 OS/GPU 메모리 상한이 아니다.
- [x] 합성 JSON 9MiB: 읽기 1.50초, 편집 전환 1.52초, 한 글자 입력 처리 약 49ms. 합성 7,000×7,000 PNG: 표시까지 0.45초. Windows WebView2 개발 실행의 단일 측정이다.
- [ ] Windows 설치본의 파일 연결과 실제 자동 업데이트·재시작. 사용 중인 설치 앱을 종료하거나 변경하지 않았으므로 통과로 간주하지 않는다.
- [ ] Linux 설치본 GUI·파일 연결·저장. 현재 PC에 Linux 배포판이 없어 직접 검증하지 않았다.

같은 앱 창의 조건부 저장은 직렬화되지만 다른 프로세스의 쓰기를 원자적으로 막을 수는 없다. 복사본 저장은 하드 링크를 지원하지 않는 파일시스템에서는 실패하며 기존 파일을 덮어쓰지 않는다.
