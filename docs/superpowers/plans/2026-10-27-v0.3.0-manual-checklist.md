## 성능 기준

32GB 개발 PC, 합성 1천만 XYZRGB+ring PCD(180MB). Rust release 단독 처리: parse 0.32s, Voxel 0.76s, SOR 6.20s, 반경 3.50s(초기 실험). 초기 release WebView2 최초 표시 5.6s, 최대 long task 131ms, 박스 선택 5.3s. 최종 재측정은 아래에 기록한다. 이 수치는 해당 합성 데이터 측정이며 모든 분포·장치에 대한 보장은 아니다.

2026-10-27 최종 Windows release WebView2: 최초 표시 **3.9s**, Voxel 미리보기 **1.245s**(1,676,400점), SOR **9.126s**(9,920,160점), 반경 **6.635s**(10,000,000점), 박스 선택 **4.225s**(4,900,000점). 모두 네이티브 계산 + 화면 재구성까지 포함한다. 전체 시나리오의 최대 JS long task **135ms**, JS 오류 0, 취소 ACK 재측정 **4ms**.

앱 PID와 자식 WebView2 프로세스 합계를 약 1초 간격으로 표본 측정: 작업 집합 기준선 **357MiB**, 피크 **2,779.2MiB**(증가 **2,422.2MiB**), private commit 피크 **2,975.8MiB**. 종료된 클라우드 창은 약 426MiB까지 회수되었다. 공유 페이지의 중복 합산 가능성과 1초 사이 순간 피크·GPU 전용 메모리 미포함을 감안한다. 실제 8GiB 하드 제한이나 VRAM 측정으로 주장하지 않는다.

최종 490만 점 저장본 88,200,166 bytes, 미리보기 49,400점 HTML 1,215,280 bytes. 네트워크 차단 Edge에서 표시·점 크기와 오류 0 확인. 실험 산출물은 OS Temp/va-browser-check에만 있으며 저장소에는 합성 소형 fixture만 넣는다.
