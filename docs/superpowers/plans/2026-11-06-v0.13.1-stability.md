> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사용자가 바로 체감하는 결함 9건(큰 Markdown 읽기 경로, ANSI 로그 거부, CSV의 CP949·관대 파싱·텍스트 폴백, 저장 시 권한 소실, 링크 우클릭·단축키·재작성 확인창·텍스트 열기 오류)을 고치고 v0.13.1로 릴리스한다.

**Architecture:** 각 결함은 해당 뷰어 모듈 안에서만 고친다. 공용 변경은 두 가지뿐이다. `src/md/file-watch.ts`에 즉시 라운드 `kick()`을 더하고, `src/text/codec.ts`의 디코드 오류를 `TextDecodeError(kind)`로 구분해 텍스트·CSV 뷰어가 같은 안내 문구를 쓴다. Rust는 `write_atomic` 한 함수만 바뀐다.

**Tech Stack:** Tauri 2 (Rust), Vite + TypeScript vanilla, vitest(happy-dom), cargo test.

**Spec:** `C:\Users\uiop3\.claude\plans\ethereal-rolling-pizza.md`의 "번들 1" 절(조사 근거 포함). 프로젝트 규칙은 `AGENTS.md`.

## Global Constraints

- 소통·문서는 한국어, 코드 식별자·커밋 메시지는 영어. 커밋은 Conventional Commits, scope 없이 `type: lowercase imperative`. main에 바로 커밋한다.
- md 저장은 고친 블록만 반영하고 읽기 모드에서는 내용이 바뀌지 않는다. 이 계획은 저장 알고리즘을 건드리지 않는다.
- 시작 속도 보호: 진입 청크와 md 청크에 새 의존성을 넣지 않는다(이 계획은 의존성 추가 없음).
- CP949는 사용자가 **명시적으로** 선택한다(자동 추정 금지). 변환은 Rust `text_codec.rs`의 무손실 경로(`platform.decodeCp949`/`encodeCp949`)만 쓴다.
- 필수 검증 5종을 커밋마다 통과한다: `npm test`, `npx tsc --noEmit`, `npm run build`, `npm run check:bundle`, `cargo test --manifest-path src-tauri/Cargo.toml`.
- 파일 유래 문자열은 textContent로만 표시한다.

## Review Focus

1. **md 파일이 10 MiB를 넘어서 커지는 중**: 읽기 창은 기존 내용을 유지하고 1초마다 stat만 하며 바이트를 읽지 않는다(Task 1 테스트 "a file that grew past the limit keeps the screen").
2. **CSV에 `"`가 든 비인용 필드를 수정해 저장**: 수정한 셀만 바뀌고 다른 셀의 원문(따옴표 포함)은 바이트 그대로다(Task 4 테스트).
3. **CP949 CSV를 UTF로 연 뒤 편집 버튼**: 디코드 실패 상태에서는 편집이 비활성이고 저장 경로로 들어갈 수 없다(Task 3 테스트).
4. **읽기 전용 파일 저장**: 속성을 몰래 풀지 않고, 임시 파일을 남기지 않으며, 한국어 메시지를 낸다(Task 5 테스트).
5. **설정 대화상자가 열린 채 Ctrl+S**: md 저장이 실행되지 않는다(Task 6 테스트, Ctrl+E와 함께).
