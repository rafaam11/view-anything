# 기본 사용성 보완

v0.10.0 공개 이후 선택한 후속 방향을 구현한다. 기본 화면은 본문 중심으로 유지하며 설정·편집 도구만 요청할 때 표시한다. 각 작업은 필수 검증 5종을 실행하고 main에 커밋·푸시한다. 이번 작업은 새 릴리스 공개를 포함하지 않는다.

1. **이미지 편집 이력**: 회전·좌우 반전·자르기를 최대 20회 실행 취소/다시 실행한다. 편집 모드의 아이콘과 Ctrl+Z, Ctrl+Y, Ctrl+Shift+Z를 지원한다. 원본에서 합성 변환을 한 번 적용하므로 이력마다 비트맵을 복제하지 않는다. 저장 지점의 미저장 상태, 분기 편집, 파일 전환·외부 갱신 시 이력 초기화를 확인한다.
2. **이미지 폴더 갱신**: 창 활성화 및 보기 메뉴의 새로고침/F5로 목록·썸네일을 갱신한다. 추가·삭제·현재 원본 삭제에도 표시 중인 이미지와 편집을 유지하고 이전/다음 이동을 제공한다. 목록 읽기·대상 이미지 디코딩 실패는 현재 내용을 지우지 않는다.
3. **현재 뷰어 설정과 TXT 표시**: 현재 뷰어의 항목만 설정에 표시하며 빈 창은 전체 표시 설정을 제공한다. TXT 글꼴·크기·자동 줄바꿈을 읽기/편집 양쪽에 적용하고 열린 창·재시작에 유지한다. Markdown 설정과 별도로 저장하고 파일 인코딩은 파일별로 유지한다. 초기화는 현재 표시 그룹에만 적용한다.

자동 회귀와 별도로 분리된 Windows WebView에서 실제 편집·undo/redo·PNG 저장/픽셀, 외부 파일 추가·삭제/오류, 설정·다중 창 동기화·재시작과 TXT 원문 보존을 확인한다. Linux GUI 및 설치본 업데이트/파일 연결은 별도 검증 대상으로 명시한다.
