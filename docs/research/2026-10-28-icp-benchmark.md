# ICP 표본 성능 점검

2026-10-28, Windows 시험 PC, 합성 데이터만 사용. 숫자는 각각 한 번 측정했으며 기기 간 성능 보장은 아니다.

- Rust release 계산 벤치마크: 입력 각 100만 점, 선택 최대 1만·5만·10만 표본에서 각각 0.005·0.038·0.086초. 세 경우 모두 대응 100%, 평행이동 오차 1e-6 미만. 시간은 표본 준비와 ICP 계산만 포함하고 파일 파싱·GPU 표시를 제외한다.
- Rust release: 입력 각 1천만 점, 10만 표본, 3회 반복, 계산 0.096초. 벤치마크 프로세스 최대 작업 집합 473.3 MiB(20ms 표본), VRAM과 별도 WebView 프로세스는 제외한다.
- 실제 Windows 개발 WebView의 동일한 100만 점 두 장면에서 1만·5만·10만 표본 미리보기까지 각각 약 0.9·4.4·5.5초. 디버그 빌드이며 계산·IPC·장면 갱신을 포함한다. 각 대응률 100%, 2회 반복, 수렴으로 표시됐다.

정렬된 동일 점군과 작은 평행이동만 사용한 결과이므로 노이즈·가려짐·불균일 분포의 정확도를 대표하지 않는다. 표본이 작을수록 빠르지만 중요한 구조를 놓칠 수 있어 기본값 10만과 선택값 1만·5만을 제공한다. 수렴 표시만으로 올바른 정합을 보장하지 않으므로 대응률·RMSE와 화면을 함께 확인해야 한다.

재실행: `cargo run --release --manifest-path src-tauri/Cargo.toml --example bench-registration -- 1000000 100000`. 첫 인자는 합성 원본 점 수, 두 번째는 표본 상한이다. 파일이나 사용자 데이터는 읽지 않는다.
