# view-anything

더블클릭하면 바로 열리는 가벼운 파일 뷰어입니다. Tauri 2로 만들었습니다.

Markdown, 일반 텍스트·코드, PDF, 이미지, JSON/YAML/CSV, 3D 모델과 포인트클라우드를 지원합니다. Windows와 Linux에서 사용할 수 있습니다.

- **Markdown**: 렌더링된 화면으로 읽고, Typora처럼 화면에서 바로 편집합니다. Mermaid, KaTeX, 목차를 지원합니다.
- **텍스트·코드**: TXT/LOG/INI/TOML과 C/C++·Python·Rust·JS/TS 등 주요 코드 파일을 깔끔한 본문 화면으로 읽고 편집합니다. 저장은 파일 메뉴, 검색은 `Ctrl+F`, 인코딩 선택은 설정 안에 둡니다. UTF-8, BOM이 있는 UTF-16을 보존하며 CP949도 선택할 수 있습니다. 혼합 줄바꿈은 읽기 전용이며 파일과 편집 결과 모두 10 MiB까지 지원합니다. 코드 실행·구문 강조는 제공하지 않습니다.
- **설정**: 제목 표시줄의 설정 버튼 또는 `Ctrl+,`에서 현재 뷰어에 맞는 항목을 엽니다. Markdown과 텍스트의 글꼴(시스템·명조·고정폭)·크기(12~24px)를 각각 설정하고, 텍스트는 자동 줄바꿈도 선택합니다. 읽기·편집에 함께 적용하고 열린 창에 동기화하며 재시작 후에도 유지합니다. 빈 창에서는 두 표시 설정을 모두 제공하고, 다른 뷰어에서는 테마 같은 공통 설정만 표시합니다.
- **3D**: STEP, IGES, STL, OBJ, PLY, glTF, GLB. 드래그로 같은 장면에 추가하고, 좌표계·단면·표시 모드를 조정하거나 단일 HTML로 공유합니다.
- **포인트클라우드**: PCD/PLY/LAS/LAZ. 원본 RGB·높이·intensity 표시, 점 속성 조회, 박스·관통 다각형 선택, Voxel/SOR/반경 필터를 지원합니다. 원본 속성을 보존하며 같은 형식으로 다른 이름 저장합니다. 파형·COPC와 좌표 정밀도 보존이 어려운 LAS/LAZ는 열지 않습니다.
- **이미지**: PNG/JPEG/WebP/BMP/GIF/SVG를 아이콘 중심 화면으로 봅니다. `Ctrl+휠`로 포인터를 기준으로 확대·축소하고 드래그로 이동하며, `Ctrl+0`으로 화면에 맞춥니다. `Ctrl+C`는 현재 이미지(편집했으면 편집 결과)를 원본 해상도로 클립보드에 복사합니다. 좌우 화살표로 폴더의 이전·다음 이미지를 엽니다. 썸네일은 보기 메뉴에서 켜고, 회전·반전·자르기는 편집 아이콘을 누른 뒤 사용합니다. 편집 결과는 원본을 보존해 PNG로 별도 저장합니다. GIF/SVG 편집·복사는 정적 결과입니다.
- **데이터**: JSON/YAML 트리와 원문 편집, CSV 표와 셀 편집을 지원합니다. UTF-8 및 BOM이 있는 UTF-16을 읽고, CSV는 수정한 셀 외의 원문을 보존합니다.
- **PDF**: 읽기 전용 페이지 이동·확대, 텍스트 선택·복사, 검색 결과 강조와 목차를 지원합니다. 암호화된 PDF는 암호 입력 후 열 수 있습니다.
- **테마**: 우측 상단 창 버튼 왼쪽의 버튼으로 다크 → 라이트 → 시스템 순서로 바꿉니다. 설정을 기억하고 열린 창에 동기화합니다.

이미지 편집은 최대 20회 실행 취소(`Ctrl+Z`)와 다시 실행(`Ctrl+Y` 또는 `Ctrl+Shift+Z`)을 지원합니다. 편집 모드에서만 이력 아이콘이 나타나며 저장한 상태로 되돌아오면 미저장 표시도 해제됩니다. 파일을 전환하거나 원본을 다시 읽으면 이력을 초기화합니다.

이미지 폴더 목록은 창을 다시 활성화할 때 갱신하며 **보기 > 목록 새로고침** 또는 `F5`로도 갱신할 수 있습니다. 현재 원본이 삭제되거나 목록·이미지 읽기가 실패해도 표시 중인 이미지와 미저장 편집을 유지합니다. 삭제된 원본 위치에서도 남아 있는 이전·다음 이미지로 이동할 수 있고, 원본 파일·폴더가 삭제돼도 편집 결과를 다른 PNG로 복구 저장할 수 있습니다. 원본 경로로의 저장은 계속 차단하며 끊어진 심볼릭 링크나 권한 오류는 경로를 추측해 저장하지 않습니다.

모든 뷰어는 같은 높이의 상단 메뉴와 공통 버튼·입력창 스타일을 사용합니다. 저장·복사본은 파일 메뉴에, 검색은 필요할 때만 여는 검색창에 두고 파일명을 본문에 중복 표시하지 않습니다. 3D의 표준 방향은 보기 메뉴와 1~7 단축키로 선택합니다.

포인트클라우드는 장면 원본 점 합계 1천만, 디코딩 2GiB/파일, 예상 작업 메모리 8GiB/앱까지 받습니다. 필터는 **미리보기 → 결과 적용** 순서이며, 최대 20회 실행 취소/다시 실행을 지원합니다. 원본은 덮어쓰지 않습니다. HTML 공유에는 점·색상·크기만 포함되며 사용자 정의 속성이나 편집/PCD·PLY 저장 기능은 포함되지 않습니다.

두 점군을 같은 장면에 추가한 뒤 처리할 점군과 기준 점군, 최대 대응 거리와 표본 상한(1만·5만·10만)을 지정해 강체 ICP 정합을 미리 보고 적용하거나 취소할 수 있습니다. 현재 장면 위치에서 시작하며 대응률·RMSE·수렴 여부를 표시합니다. 정합과 필터는 적용 순서대로 실행 취소·다시 실행할 수 있고 결과는 다른 이름으로 저장합니다. LAS/LAZ 좌표는 원본 파일의 스케일에 맞춰 양자화합니다. 정수 XYZ를 가진 PCD/PLY와 기본값이 아닌 센서 VIEWPOINT를 가진 PCD는 정합 저장을 지원하지 않습니다.

3D 조작은 Arcball과 Fly 중 선택합니다. Fly에서는 장면을 드래그해 시점을 바꾸고 W/A/S/D/Q/E로 이동합니다. 장면 트리와 점군 도구는 오른쪽 패널에 있습니다. HTML 공유에도 조작 모드와 카메라 상태가 포함됩니다.

데이터 파일은 10 MiB, CSV는 100,000셀, 이미지는 100 MiB 및 5천만 픽셀까지 열며 썸네일은 처음 1,000개를 표시합니다. 저장 전에 외부 변경을 확인하고 충돌 시 편집 내용을 유지합니다. 같은 앱의 동시 저장은 직렬화하지만, 다른 프로그램이 저장 검증과 파일 교체 사이에 쓰는 경쟁까지 파일시스템에서 원자적으로 막지는 못합니다.

CSV는 100행·10열씩 표시하며 페이지를 바꿔도 편집 내용이 유지됩니다. PDF는 100 MiB까지 열며 현재 페이지만 렌더링합니다. Markdown·데이터 편집 중 충돌이 나면 다른 이름으로 복사본을 저장할 수 있습니다. 복사본 저장은 기존 대상을 덮어쓰지 않으며 하드 링크를 지원하지 않는 파일시스템에서는 실패합니다.

> 개발 초기 단계입니다. 설계는 [docs/superpowers/specs](docs/superpowers/specs/2026-10-26-view-anything-design.md)를 참고하세요.

확장자 없는 파일이나 미등록 형식은 `Ctrl+Shift+O`의 **텍스트로 열기**로 선택할 수 있습니다. 일반 열기에서 미등록 형식을 선택한 경우에도 **텍스트로 열기** 버튼을 제공합니다. 바이너리·잘못된 인코딩과 CP949로 표현할 수 없는 문자는 저장하지 않습니다. 텍스트 저장도 외부 변경·미저장 작업을 보호하며, 복사본은 기존 대상을 덮어쓰지 않습니다.

## 개발

```sh
npm install
npm run tauri dev
```
